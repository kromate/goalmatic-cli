---
title: Contribute and release the tools
description: Work on the CLI, starter, and developer docs.
---

The CLI package is `packages/cli`. The Vue starter is under `packages/cli/templates/vue-todo`. Mintlify source is under `docs`.

Keep CLI changes separate from starter changes when they have different release risks. Update the CLI help text and this reference page together when a command or flag changes.

The CLI is published under the `beta` dist-tag. Keep command help, package
metadata, the initializer dependency, and these docs aligned before a beta release.
Verify both npm dist-tags before announcing a version.
